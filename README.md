# FinsROV-Assistant
近期关注到上海交通大学在26年上半年的时候开源了水下机器人的教程，觉得这个教程对小白入门水下机器人很有帮助，所以跟着去做了一遍，发现这个过程还是比较漫长，所以把我的经验分享给大家帮助大家快速上手，避免去踩一些坑。   
主要内容是： 
1. 详细物料清单BOM
2. 整理好的所有3D打印文件
3. 详细的电路图
4. 水下机器人开源教程电路逻辑
5. 水下机器人开源教程通讯逻辑
6. 水下机器人开源教程代码逻辑（整理好有详细注释的版本代码，开源在GitHub）
7. 如何快速上手去理解（VSCode+Keil+CodBuddy）
8. 其他你需要知道的
